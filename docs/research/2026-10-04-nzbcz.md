# NZL, CZE, BGR sovereign 5Y source follow-up

Research date: 2026-10-04 UTC. Scope: official/no-key public daily sovereign 5Y series, files, actual observation date, units, local nominal status, yield definition, reuse conditions. Research only; no product implementation. Raw-source values are not a license to redistribute. Investing.com was treated only as a naming/coverage reference; no numerical series was downloaded from it.

## Source checks and evidence

### New Zealand

The RBNZ B2 page labels periodicity Daily, records the 2026-10-02 release and shows the October 1 5-year government-bond closing yield as 4.55. It says benchmark 1-, 2-, 5- and 10-year government bond rates are indicative 5:10pm closing rates published by NZFMA, with a one-business-day lag. The current 5-year benchmark listed on the page is May 2031, effective 2025-11-17. The page's source field names RBNZ, LSEG Data & Analytics and NZFMA.

RBNZ terms: <https://www.rbnz.govt.nz/about-our-site/terms-of-use>. They permit accurate reproduction of RBNZ-owned material if RBNZ is credited, exclude third-party content from that permission, and say automated means are disallowed without RBNZ's prior written permission. The advertised XLSX returned 200 on a bounded ordinary request, so the earlier 403 is not a stable access conclusion; however, this does not override the published automation restriction. A permission/license review is required before unattended collection or republication.

### Czechia

The CNB methodology sheet precisely defines the official “Government Bond Basket Yields” series. It says source quotations are daily PSE and MTS Czech Republic reference prices; mean buy/sell reference prices are used; basket yield uses ISMA 6.3 YTM; bonds are CZK fixed-rate central-government bonds; daily selection is constrained to 3.5–6.5 years residual maturity for the five-year basket; and monthly report outputs are month-end (last business day if a basket bond has a quote that day) and monthly arithmetic averages.

ARAD user guide: <https://www.cnb.cz/aradtest/docs/guide/account-login.html>. It states most functions, including search, display and export, work without sign-in, whereas API access needs an account. API documentation states registered accounts and an API key are required: <https://www.cnb.cz/aradtest/docs/api/rest-api.html>. CNB rules allow dataset downloads and reuse with attribution but forbid web scraping: <https://www.cnb.cz/aradtest/docs/reference/rules.html>. ARAD is therefore a viable manual monthly export, but this research-only task did not make a UI export or claim a verified observation.

### Bulgaria

BNB quarterly series index advertises PDFs and XLSX workbooks for quarterly primary- and secondary-market government-securities data. The 2026 Q2 report describes those as quarter-level market data, not a daily 5Y series. BNB's Economic Review explains its reference yield curve is an extended Nelson–Siegel–Svensson curve; the curve uses daily yields of Bulgarian government securities issued and traded in international capital markets, published in the MoF Central Government Debt and Guarantees Monthly Bulletin, with BNB calculations. Example source: <https://www.bnb.bg/bnbweb/groups/public/documents/bnb_publication/pub_ec_r_2025_02_en.pdf>.

The MoF monthly bulletin catalogue showed a latest August 2026 bulletin (published 2026-09-30), but the page/API path did not provide a verified exact five-year daily observation in this pass. BNB's 2026 Q2 report includes an auction table with dated security-level annual yields, including a new issue with 2026-01-28 issuance and 2031-01-28 maturity; that is auction-market YTM for a specific bond, not a current secondary-market 5Y rate. The same distinction applies to reopenings: a new tranche's quoted yield is not a time series of daily five-year sovereign yields.

## Reproducibility and limitations

- No data were obtained from Investing.com; it was used only as an issuer/country navigation reference and does not determine officialness or reuse rights.
- No credentials, API keys, login sessions, access-control bypasses or page scraping were used.
- RBNZ's direct HTTP availability has varied (previous report recorded a 403; current bounded request returned 200). Its explicit ToS automation restriction is the controlling operational issue, not HTTP status.
- CNB ARAD allows human-operated web exports and permits programmatic REST only with a registered API key. No API key was supplied or used.
- BNB/MoF report availability establishes a primary-source lead, not a redistributable time-series license or a validated daily fixed-5Y field.
