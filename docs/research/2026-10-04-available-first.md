# 확보된 국가부터 사용하는 첫 실제 실행

사용자 지시에 따라 미연결 국가 때문에 진행을 멈추지 않고 기존 부분 순위 기능을 실행했다. 계산식, 27개국 원본 진단 목록, 품질 검사와 재배포 게이트는 변경하지 않았다.

- 실행 ID: `20261004T031647-f7bd3b63`
- 기준일: 2026-10-04
- 실행 명령: `python -m sovereign_macro run --as-of 2026-10-04 --output results/available-first`
- IMF April 2026 자료 및 해당 PDF 대조 성공, ECB FX 확보.
- HTTP 시도 44회 중 성공 응답(200/304) 24회. 공급자 요청 성공 횟수와 국가 수는 다르다.
- 5Y 수집 경로 등록 18개국, 이번 5Y 원자료 파싱 14개국, Baseline 품질 통과 6개국.
- 이번 부분 순위 대상: NOR, CAN, SWE, NLD, DEU, GBR. 실제 순위와 수치는 로컬 개인 연구 보고서에만 보관한다.
- FRA는 HTTP 429, ISL·SVK·ISR은 요청 타임아웃으로 이번 실행에서 제외했다. 과거 성공 캐시로 수집 실패를 보충하지 않았다.
- CZE는 이번 실행에서 목록과 PDF 요청 및 월별 파싱까지 성공했다. 앞선 별도 요청의 타임아웃과 구분하며, 계속 성공할 것이라고 보장하지 않는다. 관측월은 2026-07, 발행판은 2026-09로 유지한다.
- NZL·BGR·IRL·DNK·LTU·HRV·SVN·AUT·PRT는 미연결이다. 일별/단위/정의 검사를 통과하지 못한 다른 국가도 순위에는 넣지 않는다.

전체 품질 상태는 DATA_HOLD, `safe_to_use=False`다. 이는 27개국 전체 비교가 준비되지 않았다는 의미다. `usable_baseline=True` 및 유효한 `baseline_rank`는 해당 실행의 부분 Baseline 순위 대상만 표시한다. Adjusted는 0개국이며 미산출 상태를 유지한다. 누락된 축의 가중치를 다른 축으로 재분배하지 않는다.

로컬 실행 보고서의 파일 해시와 유효 국가 수, 제외 국가의 빈 순위를 확인했다. 개인 연구용 전달 파일은 이번 실행의 유효 6개국만 먼저 보는 페이지와 변경하지 않은 전체 원본 진단 보고서를 함께 포함한다. 현재 소스의 재배포 플래그는 모두 pending이며 이 로컬 수치 보고서를 공개 저장소나 커뮤니티 배포판에 넣지 않는다. 공개 모드는 기존처럼 해당 수치를 숨긴다.

코드 변경 없이 기존 실행 흐름을 사용했으므로 이번 작업에서는 단위 테스트를 새로 작성하거나 재실행하지 않았다. 기존 PR의 최신 코드 검증은 63개 테스트 및 GitHub Tests 성공 상태다. 이번에는 실제 실행 결과와 보고서 일관성을 검증했다.
