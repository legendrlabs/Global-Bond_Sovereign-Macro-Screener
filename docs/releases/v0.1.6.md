# v0.1.6 — 국채 거시 스크리너 사용판

Python 3.11 이상, API 키 없이 실행하는 공식 자료 우선 연구용 스크리너입니다.

- 불가리아의 실제 유로 도입일(2026-01-01)을 보존하고 ECB의 과거 BGN 관측을 법정 환율로 검증·환산해 KRW 기준 FX 이력을 연결합니다. 페그 불일치·결측·미래 관측은 계속 차단합니다.
- 슬로바키아 NBS 추정 5년 무이표 금리를 정의 차이 경고와 함께 연구용 Baseline 비교에 조건부 포함합니다. 원래 금리 정의와 복리 규약 미확인 상태를 보존하며 par 금리나 이표채 YTM으로 변환하지 않습니다.
- 프랑스·독일·뉴질랜드·벨기에·덴마크·슬로바키아의 공식 신용등급 진단을 수집합니다. 통화·만기 확인 수준과 평가일·확인일·최종 변경일을 구분합니다. 공식 수집 실패 시 WGB 보완 진단과 공식 실패 사유를 함께 표시합니다.
- Trading Economics는 27개국의 공식 자료를 찾는 보조 링크로만 사용합니다. 등급값·자체 점수를 채점 입력으로 가져오지 않습니다.
- 기존 IMF 발표판 저장본 재사용, 공식 5Y 우선/WGB 보완, 미국·일본·영국·스웨덴 거래량 및 한국·일본 ADB 분기 회전율 진단을 유지합니다. 서로 다른 거래량·회전율을 국가 간 유동성 순위로 사용하지 않습니다.

전체 Baseline `READY`는 27개국의 필수 입력·최신성·품질 검사가 모두 통과한 실행에만 부여합니다. 저장된 원자료 재평가에서 27개국 비교 경로를 확인했으며 이는 새로운 실시간 수집 성공을 뜻하지 않습니다. 실행마다 `quality.json`과 출처·관측일·경고를 확인하세요.

Market Quality 종합 점수와 Adjusted 랭킹은 계속 보류합니다. 신용등급과 유동성 진단은 채점하지 않으며 결측을 0점으로 바꾸거나 가중치를 재분배하지 않습니다. 공개 출력은 재배포 권한 미확인 수치를 숨기고 원본 해시를 보존합니다. 데모는 합성 자료이며 실제 등급·수집 이력을 포함하지 않습니다.

배포 절차는 통합 테스트, 설치된 wheel 테스트와 공개 데모를 검증한 뒤 wheel·소스 ZIP·SHA256SUMS.txt를 게시합니다. 개인 보고서와 원자료 캐시는 포함하지 않습니다.
